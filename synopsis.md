# Title
Plant Care Companion – Smart Houseplant Care Website

# Introduction
Plant Care Companion is a frontend web application designed to help plant enthusiasts learn about and maintain healthy houseplants through an attractive and user-friendly digital platform. Many beginners struggle with plant care because information about watering schedules, sunlight requirements, and maintenance tips is often scattered across different websites and social media platforms.
The Plant Care Companion Website serves as a centralized platform where users can explore different houseplants, learn essential care techniques, follow watering schedules, and discover useful gardening tips. The website combines a clean interface with nature-inspired visuals, making plant care both informative and enjoyable.

# Problem Statement
Many people purchase houseplants without having sufficient knowledge about their care requirements. Information regarding watering frequency, sunlight needs, and maintenance is often difficult to find or presented in a complicated manner. There is a need for a simple, organized, and visually appealing platform that provides basic plant care information in one place.

# Objectives
To create a modern and visually appealing website dedicated to houseplant care.
To provide a digital library containing information about various indoor plants.
To display a simple watering schedule interface for different types of plants.
To share useful plant care tips for beginners and gardening enthusiasts.
To highlight a featured "Plant of the Month" with detailed information.
To develop a responsive website using modern frontend technologies and creative CSS effects.

# Scope of the Project
The website focuses on delivering an engaging and responsive user experience through a nature-inspired design. It includes pages such as Home, Plant Library, Watering Schedule, Plant Tips, and Plant of the Month. The platform is designed to work smoothly across desktops, tablets, and mobile devices. Future enhancements may include personalized plant reminders, plant search functionality, user accounts, and interactive care tracking.

# Technologies Used
HTML5
CSS3
JavaScript
GitHub

# Expected Outcome
The project will result in a fully functional frontend website that serves as a helpful guide for plant lovers and beginners. The platform will provide organized information about plant care while offering an attractive user experience through responsive layouts, glassmorphism cards, nature-themed gradients, and subtle CSS animations. It will also demonstrate practical frontend development skills and modern web design techniques.

# Conclusion
The Plant Care Companion Website combines technology with nature to create an informative and engaging digital platform for houseplant care. The project not only fulfills academic requirements but also provides a practical solution for individuals who wish to care for their plants more effectively. It showcases the application of HTML, CSS, and JavaScript in developing a responsive and visually appealing frontend website while promoting awareness of plant care and sustainable living.
