# Plant Care Companion – Smart Houseplant Care Website

## Introduction

Plant Care Companion is a frontend web application designed to help plant enthusiasts learn about and maintain healthy houseplants through an attractive and user-friendly digital platform. The website provides organized information about plant care, watering requirements, sunlight needs, and maintenance tips in one convenient place.

## Problem Statement

Many beginners struggle to care for houseplants because information about watering, sunlight, and maintenance is often scattered across different sources. There is a need for a simple, organized, and visually appealing platform that provides essential plant care information in one place.

## Objectives

* To create a modern and visually appealing website dedicated to houseplant care.
* To provide a plant library containing information about different indoor plants.
* To display a simple watering schedule for different plants.
* To provide useful plant care tips for beginners.
* To feature a "Plant of the Month" with detailed information.
* To develop a responsive website using modern frontend technologies and CSS design techniques.

## Scope of the Project

The website includes pages such as **Home, Plant Library, Watering Schedule, Plant Tips, and Plant of the Month**. It is designed to provide a smooth and responsive experience across desktops, tablets, and mobile devices.

The project can be further enhanced in the future with personalized watering reminders, plant search functionality, user accounts, plant tracking, and interactive care schedules.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## Design Features

* Nature-inspired color palette
* Nature-themed gradients
* Glassmorphism cards
* Leaf and plant animations
* Responsive layouts
* Interactive hover effects
* Clean and user-friendly interface

## Expected Outcome

The project will result in a fully functional and visually appealing frontend website that provides useful plant care information for beginners and plant enthusiasts. It will demonstrate practical knowledge of HTML, CSS, JavaScript, responsive web design, animations, and modern UI design techniques.

## Conclusion

Plant Care Companion combines technology and nature to create an informative and engaging digital platform for houseplant care. The project provides a practical solution for users who want to learn how to care for their plants effectively while demonstrating modern frontend development skills. It also provides a strong foundation for future features such as personalized plant reminders and interactive plant tracking.
