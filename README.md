# 🌱 Plant Care Companion

A cozy, nature-inspired web app that helps you keep your houseplants happy — track watering schedules, browse a plant library, pick up care tips, and discover a featured Plant of the Month.

![Status](https://img.shields.io/badge/status-in%20development-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- **🏡 Home** — Welcoming landing page with quick access to all sections
- **📚 Plant Library** — Browse and search plants by type, light needs, and care difficulty
- **💧 Watering Schedule** — Interactive UI to track which plants need watering today/this week
- **🌿 Plant Tips** — Bite-sized care advice on light, soil, humidity, and pruning
- **🏆 Plant of the Month** — A featured plant spotlight with fun facts and care instructions

## 🎨 Design

- Nature-themed gradients (sage, moss, cream, terracotta accents)
- Glassmorphism cards with soft shadows and blur
- Subtle leaf animations and organic, rounded shapes
- Fully responsive across mobile, tablet, and desktop

## 🛠️ Tech Stack

- **Frontend:** HTML + CSS + JavaScript
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Data:** Local/mock JSON (for now)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/plant-care-companion.git

# Navigate into the project
cd plant-care-companion

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app should now be running at `http://localhost:5173` (or whichever port Vite assigns).
